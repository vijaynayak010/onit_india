## 2. Missing Pages & Backend Dependencies

1. **No Dedicated `/provider/task-agreement` Page:**
   - **Current Behavior:** Performer offer acceptance/decline is handled by `PerformerTaskAgreementPage.jsx` (`/performer/task-agreement/:id`) via `PUT /tasks/assignments/:assignmentId/accept-offer` and `decline-offer`.
   - **Backend Gap:** No Provider-side agreement endpoint, downloadable legal contract PDF endpoint, or custom term-negotiation API exists in `provider/services/api.js`.
2. **No Dedicated `/provider/invitations` List Page:**
   - **Current Behavior:** Invitations are sent per-performer (`sendTaskInvitation`) and verified per-task (`getTaskInvitations`) inside `TaskPerformerProfilePage.jsx`.
   - **Backend Gap:** There is no cross-task `GET /providers/me/invitations` endpoint in `provider/services/api.js`.
3. **No Dedicated Per-Task Shortlist API:**
   - **Current Behavior:** `SavedPerformersPage.jsx` (`/provider/saved-performers`) supports bookmarking performers globally (`GET /providers/saved-taskers` + `localStorage` sync). No per-task shortlist/comparison endpoint exists.
